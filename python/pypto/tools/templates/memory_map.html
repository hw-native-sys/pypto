Memory Map

Down is lifetime: the y axis is the dump's own line number, which is statement order. Across is address, on one shared byte scale: every panel is as wide as the space it shows, so a box's width means the same number of bytes wherever it sits and the panels are comparable against each other. By default a panel spans its hardware limit, so the filled fraction is the usage; x axis: used shrinks every panel to its high-water mark instead, which spends the width on the bytes actually allocated. One box is one tile's live range over the bytes its MemRef owns. Click a box to keep its lines highlighted and mark every mention of its name in the IR source, and switch individual spaces off when you only care about one of them. SSA aliases that share a slot with touching live ranges (phi / yield chains) are merged into a single box, with +N counting the names folded in; a dashed box is a view into a larger allocation on the same base; a red box means two different bases overlap in address and lifetime at once.
