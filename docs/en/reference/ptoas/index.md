# PTOAS

PTOAS parses, verifies, optimizes, and compiles PTO IR. Use this section when
reading generated `.pto` files or looking up instruction syntax and semantics.

The navigation contains the PTO IR manual, VMI instruction references, and pass
designs for event ID synchronization, A5 buffer ID synchronization, and memory planning. These manuals are rendered directly from the
[PTOAS GitHub mirror](https://github.com/hw-native-sys/PTOAS), which is automatically
synchronized from [GitCode](https://gitcode.com/cann/pto-as). Corrections belong in
the GitCode repository. Every imported page identifies its source revision.

Upstream manuals retain their original language in both language views.

See [documentation updates](../../dev/ptoas-docs.md) for build and refresh instructions.
