# 算子

某个算子属于哪个命名空间、如何在它们之间做选择，以及算子表面都有些什么。

> **前置**：[类型](../language/00-types.md)。

## 本章是什么

两页，刻意写得很薄：

| 页面 | 覆盖内容 |
| ---- | -------- |
| [选择命名空间](00-dispatch.md) | 在 `pl.*`、`pl.tensor.*`、`pl.tile.*` 之间取舍的规则，以及统一形式何时用不了 |
| [算子目录](01-catalog.md) | 每个算子家族一行，附上可达它的命名空间 |

**这里不重复签名。** `pl.__all__` 中几乎每个算子都带 docstring，那份 docstring 就是参考 —— 手工维护的签名表在一个版本之内就会与它漂移。[API 参考](../../api/index.md)渲染的正是这些 docstring，目录里每个名字都直接链进去。所以目录回答"有些什么、叫什么名字"，API 参考回答"参数是什么"。

至于「怎么用这个算子做出有用的东西」，答案是一个完整例子而不是一张表 —— 见 [教程](../tutorials/index.md)，或仓库里的 `examples/beginner/` 与 `examples/intermediate/`。
