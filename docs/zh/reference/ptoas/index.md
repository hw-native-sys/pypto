# PTOAS

PTOAS 负责 PTO IR 的解析、验证、优化与编译。阅读生成的 `.pto` 文件，
或查询指令语法和语义时，可使用本专区。

导航包含 PTO IR 手册、VMI 指令参考，以及 event ID 同步、A5 buffer ID 同步
和内存分配 pass 的设计说明。文档直接取自
[PTOAS GitHub 镜像](https://github.com/hw-native-sys/PTOAS)，该镜像由
[GitCode](https://gitcode.com/cann/pto-as) 自动同步。文档修订应提交到
GitCode 仓库。每个导入页面都标明来源版本。

两个语言视图中的上游手册均保留原文语言。

构建与更新方式见[文档更新](../../dev/ptoas-docs.md)。
